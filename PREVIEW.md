# Арсенал и инструменты зрителя — тестовая версия

Изменения находятся в отдельной ветке. Публикация GitHub Pages происходит только после слияния в `main`.

- Арсенал по категориям оружия для коллекции и вишлиста. Есть режим всех скинов, поиск, сортировка, цены, фильтры БП и редкости.
- Логотип «кошачий прицел» и слоган «Каждый скин под свой вайбик».
- Тир-листы: Vandal, Phantom, ножи, любое оружие или весь каталог. Ряды можно переименовать, перекрасить, переставить, добавить и удалить. Перенос мышью или нажатием на скин и место. Скачать PNG.
- Рулетка владельца не предлагает добавлять принадлежащий ему скин в вишлист.
- Набор зрительской рулетки и черновики тир-листов сохраняются в браузере. Они не изменяют коллекцию владельца и не синхронизируются между устройствами.
- Публичная загрузка включает весь публичный каталог для личных инструментов зрителей. Доступ к сохранённым данным владельца по-прежнему ограничен существующей RLS/RPC моделью. Миграции базы не требуются.

## Проверка

`npm test` — фильтры, цены, движение скинов в тир-листе, категории и действия после рулетки.

`npm run build` — TypeScript и production build.

`npm run build:demo -- /absolute/path/skin-vault-preview.html` — самостоятельный HTML с демонстрационными данными и переключением владельца/зрителя. Не подключается к Supabase. Изображения скинов требуют интернета. Изменения демонстрационной коллекции живут до перезагрузки. Черновики demo используют отдельные ключи localStorage.

Облачный браузер не разрешает открытие локальных HTML. Визуальная проверка на ПК/телефоне и скачивание PNG требуют проверки в обычном браузере перед слиянием. Если источник изображений недоступен при экспорте, PNG содержит названия и сообщает о пропущенных картинках.
